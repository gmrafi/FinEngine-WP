== Description ==

FinEngine Fintech is a modern, research-backed Full-Site Editing (FSE) block theme designed specifically for fintech organizations, banking portals, microfinance institutions, financial advisory firms, and computational research initiatives.

Engineered under the Centre for Fintech and Strategic Business Research (CFSBR) computational initiative by Md Golam Mubasshir Rafi, FinEngine Fintech delivers zero-bloat performance, clean typography, accessible color contrasts, and ready-made block patterns.

= Dual Ecosystem Integration =
FinEngine Fintech is engineered to work seamlessly alongside the official FinEngine Calculator plugin:
* **Native Financial Block Patterns:** Instant hero sections, 3-column KPI metrics grids, and pre-styled loan simulation containers.
* **Elementor Page Builder Compatibility:** Full-Width and Canvas page templates allowing drag-and-drop landing page design.
* **Full-Site Editing (FSE):** Complete control over headers, footers, typography, and color palettes via the WordPress Site Editor.
* **100% Client-Side Speed:** Ultra-lightweight CSS variables, zero jQuery dependencies, and clean semantic HTML5 markup.

== Installation ==

1. In your WordPress admin dashboard, navigate to **Appearance > Themes**.
2. Click **Add New** and then **Upload Theme**.
3. Select `finengine-fintech.zip` and click **Install Now**.
4. Click **Activate**.
5. Customize your site via **Appearance > Editor** (Site Editor).

== Recommended Plugins ==

For the full fintech interactive experience, FinEngine Fintech recommends:
* **FinEngine Calculator** (https://wordpress.org/plugins/finengine-calculator/): Provides deterministic, reducing-balance loan calculators with zero float drift and South Asian Lakh/Crore grouping.
* **Elementor** (https://wordpress.org/plugins/elementor/): Drag-and-drop page builder compatible with the theme's full-width templates.
